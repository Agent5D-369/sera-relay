# Support

For setup questions, first check the installation and first-use steps in [README.md](README.md), then search existing GitHub issues. If you cannot resolve the problem, open an issue with the steps you took, what you expected, what happened, and the Sera Relay version and your Windows or macOS version.

Use the bug report template for reproducible problems and the feature request template for ideas. Do not include private WhatsApp content, transcripts, QR codes, session files, Sera tokens, or workspace credentials. Replace message text and names with synthetic examples.

This is an early beta maintained on a best-effort basis. There is no guaranteed response time.
