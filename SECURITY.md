# Security

Please do not post vulnerability details, tokens, session data, or exploitable steps in a public issue.

Use GitHub's private vulnerability reporting for this repository when available. Include the affected version, Windows version, impact, and concise reproduction steps. If private reporting is unavailable, open a minimal issue asking maintainers for a private reporting route; do not include exploit details or secrets.

Do not send real voice notes, transcripts, WhatsApp session files, Sera URLs, or credentials in a report. Redact identifying details and use synthetic data where possible.

Sera Relay is beta software distributed as an unsigned Windows package. Install only releases from the project's GitHub Releases page and review the source and release notes before use.
